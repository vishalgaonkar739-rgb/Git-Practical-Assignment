## Purpose of the Repository

This repository is created for completing and practicing Git and GitHub practical exercises.

## Objectives of the Practical

* To understand the basics of Git and GitHub.
* To create and initialize a Git repository.
* To track and manage files using Git.
* To learn staging and committing changes.
* To connect a local repository with GitHub.
* To push local changes to a GitHub repository.
* To clone a GitHub repository to a local machine.
* To understand basic version control concepts.

## Git Commands Learned

1. `git init` – Initialize a Git repository.
2. `git status` – Check the current status of the repository.
3. `git add` – Add files to the staging area.
4. `git commit` – Save changes to the repository.
5. `git log` – Display commit history.
6. `git remote` – Manage the connection to a remote repository.
7. `git push` – Upload local changes to GitHub.
8. `git pull` – Download and integrate changes from GitHub.
9. `git clone` – Create a local copy of a GitHub repository.
